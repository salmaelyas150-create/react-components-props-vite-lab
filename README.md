# React Components and Props Lab

## Description

This project is a personal blog website built with React. It demonstrates the use of reusable components, JSX, and props to display blog information dynamically.

## Component Structure

- App
  - Header
  - About
  - ArticleList
    - Article

## Features

- Displays the blog title.
- Displays a blog image with accessible alt text.
- Shows a short description of the blog.
- Displays multiple blog articles using React components.
- Passes data through props.

## How to Run the Project

1. Open the project folder.
2. Install the project dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the URL shown in the terminal (usually `http://localhost:5173`).
